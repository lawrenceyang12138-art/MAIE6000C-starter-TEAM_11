# C 讲稿草稿（约 3 分钟内，待本人计时）

我负责检索、模型和评测。输入是 B 解析出的文本块，输出是带文件版本、页码和原文的搜索结果。

关键词检索用 PostgreSQL 全文索引。英文按词匹配，中文按连续双字词匹配，所以不需要安装数据库中文分词插件。结果按文件去重，每份文件保留一个证据块。

语义检索使用固定版本的本地多语言 E5，向量为三百八十四维，保存在 pgvector。运行时只读本地模型，不联网下载，也不把文档发到云端。混合搜索把关键词和语义分数按零点六五与零点三五加权。

可靠性上，文本先保留，向量分批生成。任何一批失败，都不会发布半成品向量。AI 服务关闭、超时或向量不兼容时，接口会明确提示已经降级到关键词搜索。我们实际停止了 AI 进程，五条关键词查询仍全部通过。

评测使用冻结的十条内部查询：关键词五条，语义五条。关键词文件和页码 Top-1 是五比五，语义文件和页码 Top-3 是四比五。有一条账户问题找对文件却选错页码，我们保留为失败。语料是十二份合成文档，因此只能说明模块烟雾测试，真实 PDF、授权和界面还需要与其他成员整合验收。

展示时我会先说明结果的版本与页码，再说明停 AI 后的降级，最后展示完整评测表和失败项。
