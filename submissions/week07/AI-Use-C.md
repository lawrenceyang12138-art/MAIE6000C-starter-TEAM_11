# C 模块 AI 使用说明草稿

开发使用了 Codex 协助读取任务材料、设计并生成 Python/SQLAlchemy/FastAPI 实现、编写测试与文档，以及执行本地 SQLite、PostgreSQL/pgvector、模型推理和 HTTP 验证。代码和验证命令保存在仓库；逐条评测及失败项保存在 evidence/C。

本说明只记录工具使用事实，尚未由组员本人完成逐行复核、签署或课程平台提交。组员 C 需要理解中文切词、E5 前缀与池化、向量版本检查、混合排序、页码评分和失败降级，并对最终提交负责。

产品 AI 功能为在本机运行的多语言 E5 embedding，与使用 Codex 辅助开发是两件事。模型只通过显式准备命令下载，产品请求路径不调用云端模型。开发与评测数据为手写合成资料，没有使用私人真实文件或客户资料。团队最终 AI Use Statement 应由 D 根据各人实际使用合并并核对课程格式。
