# D 演示脚本 - 2026-10-19 修订草稿

目的：用六步展示本地只读文件助手的最窄链路，讲清楚异步扫描、真实检索、版本证据、
异常与降级，再在 M1 放行后展示小范围人工复核。预计 6 分钟，由 D 主持，A/B/C
解释各自模块。没有实际完成的步骤，直接说明阻断和责任人，不用模拟返回顶替。
本稿超过 600 字；当前录制素材是合同测试，并不是正式产品验收。

## 1. 确认本地来源与只读边界（约 45 秒）

打开目录页，展示 API 模式徽标；选择服务提供的挂载 ID 与相对目录，说明源 PDF
保持只读，浏览器不接收宿主机绝对路径。核对固定清单为 16 记录，12 正常、3 异常、
1 不支持。正式演示前先运行 fixtures 与 gold 校验，保留输出和 Git 版本。若挂载接口
不可用，展示错误，不能自动切换到 Mock。三种真实场景分别从独立、干净演示库开始。

## 2. 提交授权并观察异步任务（约 60 秒）

点击授权一次，核对网络 HTTP 202 与服务产生的 Root/Job，避免重复提交。
展示任务 pending/running/completed 与 Root 文件阶段计数的差别：扫描结束只说明发现完成，
并不表示解析和 embedding 完成。计数缺失时应显示未知，而不是假造 100%。等待正常件
就绪，异常件分别显示原因。再次扫描用于核对文件/版本不重复；D 记录 UI 截图，A
核查数据库及任务尝试次数。当前分支授权响应尚未接齐，正式运行前由 A 确认平铺封装。

## 3. 关键词检索并打开版本证据（约 75 秒）

在结果页的内容搜索框输入冻结关键词，选择 Keyword 并提交。展示 Network 的
`POST /search`、授权 root_id 和返回的 chunk_id。强调旁边的小型文件目录筛选框只是
目录过滤，不能代替内容检索。依次核对文件名、相对路径、不可变版本、页码、匹配理由；
排序分数不解释为概率。点击结果后由 `GET /evidence/{chunk_id}` 打开原文，检查 chunk、
文件、版本、ordinal、页码与路径相符。实际原文和哈希放在检查器中，10 项核对由 B
独立复验。冻结语料目前较模板化，不能据此宣称真实主题检索质量。

## 4. 空结果、异常和重试（约 60 秒）

提交一个无匹配查询，应显示成功但无结果；随后演示服务暂时不可用，错误不能显示为
空结果。恢复服务后按 Retry search 重读。查看解析失败/不支持文件，说明错误不会阻塞
正常件。对独立副本制造版本变化或来源失效，再打开旧命中：应显示过期或缺失来源，
隐藏缓存段落与证据，提示刷新。若任务状态为 failed，可点 Retry failed job；D 已按
暂定合同接入 `POST /jobs/{job_id}/retry`，只有 202 且同一 Job/Root 变为 pending
才显示排队成功。真实接口仍待 A 确认与装配；尝试记录由 A 在后端核对。服务拒绝或
回执不确定时先重读状态，不自动重发；不能把“读取重试”说成已重新执行任务。

## 5. 本地 AI 与关键词降级（约 60 秒）

M1 基础关键词和证据通过后，选择 Hybrid 或 Semantic，记录请求模式和有效模式。
C 主导停用本地 AI，再发冻结关键词，检查响应的 degraded/degradation_reason 和
页面提示。保留五次真实查询结果；如果模型或向量未就绪，说明降级原因。没有云端回退，
也不把模拟的 1.0 排序分数当成模型质量。语义 Top-3 的实际五查询结果由 C 提供，
D 只展示服务返回的能力状态。本次合同截图只能证明 UI 正确显示降级字段。

## 6. 有证据候选与人工复核（约 60 秒，仅 M1 放行后正式演示）

打开 Relations，选择当前文件版本，展示 person/project/topic 至少各一条候选与规则
来源。候选不是已确认知识。逐条打开源片段，核对版本、页码与完整 quote；无法定位的
候选保持复核禁用。Human Review 页输入实际复核人，先确认，再纠正到一个真实存在的
entity ID，最后拒绝；等待服务器回执后状态才改变。每次保存携带 expected_revision，
并产生新 revision。用两个窗口制造冲突，应返回 review_conflict，禁止覆盖，重读后再
由人决策。当前缺少真实路由/写库证据，合同样例始终带水印，不作为正式演示完成记录。

收尾时展示 [M1 表](m1-checklist.md)、[范围记录](scope-decision.md) 和
[进度](ui-progress.md)，说明当前 M1 未签认。待三场景、5/5 关键词、10/10 原文及
P0/P1 关闭并由四人确认后，再安排正式录像与最终材料冻结。
