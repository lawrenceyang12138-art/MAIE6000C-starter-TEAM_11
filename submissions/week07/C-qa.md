# C 问答草稿

## 1. AI 不能用时，为什么搜索还能工作？

关键词索引和文本保存在数据库，搜索的 keyword 模式不请求 AI。hybrid/semantic 请求遇到关闭、连接失败、超时或不兼容向量时退回 keyword，响应明确给出 effective_mode 与 degradation_reason。向量生成失败也不会删除文本。已用真实 HTTP 进程验证停止 AI 后的五条关键词查询，不只是模拟返回。

## 2. 语义 4/5 是否说明模型已经达到产品精度要求？

不能。这里是十条冻结内部查询中的五条语义烟雾测试，资料是十二份手写合成文档，样本太少，不能据此推断泛化表现。评分同时检查文件与页码，一条账户查询找对文件但选错页码，所以仍为失败。应在 B/D 验证的真实 PDF 语料和独立答案上继续评测，同时保留失败记录。
