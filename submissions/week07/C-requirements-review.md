## 本轮发现并修复的问题

1. **部分向量状态漏报与语义评测误计。** 纯语义搜索在仍有文本块未向量化时曾返回 `degraded=false`，评测可能计为成功。现在 semantic 和 hybrid 均报告 `partial_embeddings`，降级语义不计成功，已加回归。
2. **损坏模型清单未正常降级。** `sha256` 被写成数组时曾抛出 `AttributeError`。现在校验结构并返回 `EmbeddingUnavailable(local_model_unusable)`，沿现有 503 / 关键词回退路径处理。
3. **两项原有测试漏收。** `test_api_integration.py python` 名称错误，已改为 `test_api_integration.py`，原有测试内容不变。

另补验了向量第二批失败时已有向量保留的场景。边界复现前后记录在 `evidence/C/review-edge-before.json` 和 `review-edge-after.json`，并非只靠静态推断。

## 合并前必须解决的合同问题

已只读核对远程 `w7-parsing` 的 `060f92d`：B 使用 `files / file_versions / source_chunks(version_id, ordinal, page_number)`，C 草案使用 `source_files / source_versions / source_chunks(source_version_id, chunk_index, page_start, page_end)`。

两套迁移都从初始版本分出、都创建 `source_chunks`，会产生多个 head 和重复建表；已有 B 的解析/关系证据也不能直接读取 C 的不同字段。此项为**合并前 P1**，由 A 主导统一模型和增量迁移，C/B 配合，不是当前独立运行失败。详见 `docs/search-contract-differences.md`。

附件规定公共模型与迁移归 A。C 本地虽已标注为草案，**仍不能据此声称公共合同已经符合流程**；合并前须完成 A 的确认及对应适配。本次没有把 B 分支合并进来，也没有修改其文件或数据库。
